# Publio Follow Buttons for Google News and Google Discover

A WordPress Gutenberg block with up to three customizable buttons linking to
Google News (follow), Google Discover, and preferred-source settings. Each
button's visibility, URL, label, and appearance (colors, font size/weight,
border) are configurable in the block editor.


## Build

```bash
npm install
npm run build        # one-off compile into build/
npm run start        # watch mode for development
npm run plugin-zip   # produce an installable zip
```


```bas
npm run env:start    # requires Docker; opens WordPress at localhost:8888
```
