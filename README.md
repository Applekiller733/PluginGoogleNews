# Publio Follow Buttons for Google News and Google Discover

A WordPress Gutenberg block with up to three customizable buttons linking to
Google News (follow), Google Discover, and preferred-source settings. Each
button's visibility, URL, label, and appearance (colors, font size/weight,
border) are configurable in the block editor.

## Project structure

This is a **source-only** distribution. You edit files in `src/`; the
`build/` folder is generated by the build step and is not committed.

```
publio-follow-buttons-google-news-discover.php        Plugin bootstrap. Registers the block from build/.
src/
  block.json                Block metadata + attribute definitions (source).
  index.js                  Client entry: registers the block.
  edit.js                   Editor UI (React/JSX): sidebar controls + preview.
  render.php                Server-side render. Outputs the front-end HTML.
                            All user style values are sanitized here.
  style.scss                Front-end + shared styles (structure/layout only).
  editor.scss               Editor-only styles.
readme.txt                  WordPress.org directory readme.
package.json                Build scripts and @wordpress/scripts dependency.
languages/                  Translation template (.pot).
```

### Why render.php?

This is a **dynamic block**: its front-end HTML is produced by PHP
(`render.php`) on every page load, not frozen into post content at save time.
The JS `save` function returns `null`; `render.php` does the real rendering.
This keeps existing posts up to date when the block changes and keeps all
output escaping/sanitization server-side. After building, `render.php` is
copied into `build/` and referenced by `block.json`'s `render` field.

## Build

```bash
npm install
npm run build        # one-off compile into build/
npm run start        # watch mode for development
npm run plugin-zip   # produce an installable zip
```

`@wordpress/scripts` transpiles `src/*.js` (JSX) into `build/index.js`,
compiles the SCSS, generates `build/index.asset.php` (dependency manifest),
and copies `block.json` and `render.php` into `build/`.

## Testing

See [TESTING.md](TESTING.md) for the full workflow: building, runtime testing

npm run env:start    # requires Docker; opens WordPress at localhost:8888
